# 吴川花园住宅 · A方案

原A方案升级为朝西独栋住宅，移除左右两侧小房，参考用户提供图片的灰瓦交叉坡屋顶、米白抹灰、暖木窗框、二层露台、黑色栏杆和拱券门廊。

- 原图1130㎡地界、北侧55m投影尺度保持一致，1个场景单位=1米。
- 主屋西向面宽16m、进深12.5m，占地200㎡。正门和主要露台朝西。
- 默认两层：首层200㎡，二层实体153㎡，合计353㎡；另有47㎡室外露台。三层示意506㎡，支持一/二/三层切换。
- 保留三个2.8×5.5m车位、6m倒车通道、2m围墙。
- 新增西南投篮练习区：净活动面8×6m，四周各1.5m缓冲，整体11×9m；含单篮架和三侧挡球网，为非标准家用练习区。
- 南侧花园茶席、高畦菜园、独立网围鸡舍与服务步道；后院为曲线观赏池塘、木质拱桥、仿真景石、分层花境与临池小亭，另有无需过桥的连续环池平路。
- 原后院长凳改为灰色低坡顶、木柱的临池小亭，四柱间距3.6×2.6m，含四人茶桌椅；平接环池步道。
- 本版不建泳池，按最新要求在后院增加观赏池塘、拱桥与仿真景石；原西南小水景移除。步道连接前后花园、投篮区、菜园和鸡舍。
- 支持手机、鼠标旋转缩放，加载进度、雨景/日光/傍晚、尺寸方位和一楼剖面。

## 运行与发布

静态网页，不需要构建。运行 `python -m http.server 8771` 后访问 `http://localhost:8771/`。
GitHub Pages使用main分支根目录，请保留.nojekyll。所有运行资源均在仓库中，无CDN或API密钥。
