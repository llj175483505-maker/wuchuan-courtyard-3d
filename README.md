# 吴川庭院 · 3D 空间预览

按总平面图尺寸重建的现代中式庭院概念方案。主屋占地 20 × 10 米（200㎡），支持一层、两层、三层切换，包含三车位、东侧水庭、西侧茶席和两米围墙。

- 鼠标左键旋转，滚轮缩放，右键平移。
- 手机单指旋转，双指缩放和平移。
- 可切换日光、雨景、傍晚灯光，以及屋顶和尺寸显示。

## 发布

这是不需要安装依赖或构建的静态网站。GitHub Pages 使用 `main` 分支的根目录作为发布源。

请保留 `.nojekyll`，以确保 `vendor` 目录中的 Three.js 模块被完整发布。所有运行资源已包含在仓库中，不依赖本机服务或 API 密钥。

## 本地查看

在仓库根目录运行 `python -m http.server 8765`，然后访问 `http://localhost:8765/`。
